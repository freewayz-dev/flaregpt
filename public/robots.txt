# FlareGPT — production
# The only two public, indexable URLs are / and /terms; everything under
# /app is a gated, personalized dashboard (wallet-specific data, settings,
# chat history) that has nothing to offer a search index and would just
# read as thin/duplicate content per-wallet. See sitemap.xml for the
# canonical list of what should actually be crawled.
