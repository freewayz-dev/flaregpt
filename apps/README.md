# apps

Each subdirectory here is an independently deployable application.

- `web` — the existing FlareGPT dashboard (Vite + React, deploys via Vercel). Arrives in Phase 1 of the mobile-architecture migration.
- `mobile` — the React Native / Expo app (deploys via EAS). Arrives in Phase 7.

See the FlareGPT Mobile Architecture Plan artifact for the full migration sequence.
